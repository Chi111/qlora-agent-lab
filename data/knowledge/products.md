# 产品使用与排查（Mock 演示）

## 显示器亮点

1. 断开并重新连接视频线，确认接口没有松动。
2. 更换视频线或电脑接口，排除信号源问题。
3. 使用纯色测试页面确认亮点是否固定在同一位置。
4. 若亮点持续存在，请拍摄照片并联系售后进行检测。

## 机械键盘无响应

1. 重新插拔 USB 线并更换电脑接口。
2. 若键盘支持有线和无线模式，确认模式开关位置正确。
3. 在另一台电脑上测试，排除系统驱动问题。
4. 问题仍存在时，可申请售后检测。

## 鼠标连接异常

1. 无线鼠标请先检查电量和接收器。
2. 蓝牙鼠标可删除原配对记录后重新配对。
3. 有线鼠标可更换 USB 接口进行测试。
